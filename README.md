# Codename-FigLicious

GNOME HOME is being built on Piglet, with a related visual language and room for features to be added independently.

## Current build

The initial build boots directly to a static 480×320 dashboard. It intentionally includes no navigation, controls, device integrations, or other feature behavior.

Open [`dashboard-preview/index.html`](dashboard-preview/index.html) in a desktop or mobile browser to view it.

Future functionality will be introduced one feature at a time in its own branch.
